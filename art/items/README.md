# Модели предметов автора: размеры и вид в каждом контексте

Исходники автора — Bedrock-модели из Blockbench (`*.geo.json` + текстура). Игра читает их копии:
`src/main/resources/assets/murim/bedrock/<имя>.geo.json` и `textures/item/<имя>.png`. Рисует их общий
рендер `client/bedrock/BedrockItemRenderer` (BEWLR), вид в руке и в инвентаре задаёт JSON модели
предмета `src/main/resources/assets/murim/models/item/<имя>.json`, блок `display`.

## Как читать размеры

- **16 единиц geo = 1 блок.** Модель рисуется в натуральном размере из файла, без подгонки длины.
- Начало координат Bedrock-модели (низ, центр) стоит в точке **(8, 0, 8)** Java-модели предмета — так же,
  как в режиме Display у Blockbench. Поэтому трансформы, выставленные в Blockbench → Display, переносятся
  в JSON один в один.
- `display`: `rotation` — градусы (X, Y, Z); `translation` — пиксели (1/16 блока); `scale` — множитель.
  Порядок применения: масштаб вокруг центра модели (8, 8, 8) → поворот → сдвиг.
- Масштаб вокруг центра опускает рукоять, если она ниже центра: при `scale` 1,5 рукоять на высоте y≈2
  уходит вниз на (8 − 2) × 0,5 = 3 px, поэтому сдвиг по Y увеличен на 3.

## Меч Хуашань — `huashan_sword`

Файлы: `art/items/huashan_sword/huashan-sword.geo.json`, `huashan-sword.png` (geo-текстура 32×32,
PNG 128×128). Модель обновлена автором 04.10: натуральная длина — 23 единицы ≈ 1,45 блока (от навершия
y = −0,25 до острия y ≈ 22,9; раньше 25,9), клинок лежит в плоскости XY, рукоять — y ≈ −0,25…4,6, гарда —
y ≈ 4,6. Рукоять не сдвинулась, поэтому трансформы ниже остались прежними; в руке при scale 1,5 меч ≈ 2,2 блока.
Все 282 грани текстурированы (офлайн-рендер `tools/art/geo_preview.py`), растянутых и пустых нет.

| Контекст | rotation | translation | scale | Как выглядит |
|---|---|---|---|---|
| thirdperson_righthand / lefthand | 0, 90, 0 | 0, 6.75, 0 | **1.5** | в руке остриём вверх, плоскость клинка боком к камере; длина ≈ 2,4 блока (автор 04.10: «в 1,5 раза больше») |
| firstperson_righthand / lefthand | −14, 90, 0 | 0, 7, 0 | **1.5** | справа внизу экрана, остриё уходит вверх за край кадра |
| gui | 0, 0, 45.75 | 3, −3, 0 | 0.8 | по диагонали слота из угла в угол, остриё вверх-влево |

| fixed (рамка) | 0, 0, 45.75 | 3.5, −3, 0 | 1 | по диагонали рамки |

Исходные значения — блок `display` из .bbmodel автора (`backup_3.10.26_22.28_huashan-sword_ge.bbmodel`);
изменены только руки: scale 1 → 1,5 и сдвиг по Y +3.

## Деревянный меч — `wooden_sword`

Та же модель, что у Меча Хуашань (`assets/murim/bedrock/huashan_sword.geo.json`), своя текстура —
`art/items/wooden_sword/wood.png` от автора (04.10), копия в `textures/item/wooden_sword.png`. Текстура той же
раскладки UV и того же размера 128×128, что `huashan-sword.png`, поэтому ложится один в один (проверено
офлайн-рендером). Трансформы и размеры — ровно как у Меча Хуашань (модель предмета — копия
`models/item/huashan_sword.json`), включая scale 1,5 в руке. Характеристики — как у ванильного деревянного
меча (урон 4, прочность 59), в теге `minecraft:swords` — техники меча с ним работают.

## Кинжал Тан — `tang_dagger`

Файлы: `art/items/tang_dagger/dagger-tang.geo.json`, `tang-dagger.png` (geo-текстура 16×16).
Натуральная длина — ≈ 12 единиц ≈ 0,76 блока (y = 3,3…15,5), гарда на y ≈ 8 (точка хвата), клинок

## Как поменять вид

1. В Blockbench: File → Convert Project → **Java Block/Item**, вкладка **Display**, выставить контекст.
2. Скопировать числа контекста в `models/item/<имя>.json` → `display` (те же три поля).
3. Если поменялась сама модель — заново экспортировать geo в `art/items/<имя>/` и скопировать в
   `src/main/resources/assets/murim/bedrock/`.
4. Проверка без игры: `python3 tools/art/geo_preview.py <geo> <png> out.png` — виды спереди, сбоку,
   сверху и изометрия по той же математике, что в игре.
